# تب جدید ایران بروکر (Iran Broker New Tab)

اکستنشن Chrome (Manifest V3) که صفحهٔ تب‌جدید مرورگر را برای معامله‌گران فارسی‌زبان فارکس/کریپتو/بورس
به یک داشبورد کاری تبدیل می‌کند: قیمت لحظه‌ای بازارها، تقویم اقتصادی، فید محتوا، ژورنال معاملات،
فوکوس‌مود و دستیار هوش‌مصنوعی «آیرا».

> ⚠️ این README بر پایه حسابرسی مستقیم کد امروز (نه ادعای مستندات قدیمی) بازنویسی شده است. اگر بین
> این سند و کد فعلی مغایرتی دیدید، **کد منبع حقیقت است** — لطفاً Issue باز کنید.

## ویژگی‌ها

- قیمت لحظه‌ای ۴ بازار: کریپتو، فارکس/طلا/نفت/DXY، بازار آزاد ایران (دلار/طلا/سکه)، بورس تهران
- تقویم اقتصادی و هاب روزانه (آب‌وهوا، مناسبت‌ها، دسترسی سریع قابل‌شخصی‌سازی)
- ژورنال معاملات: ثبت دستی، ورودی از فایل تاریخچهٔ MT4 (CSV)، خروجی CSV سازگار با اکسل فارسی، آمار R:R و نقشهٔ حرارتی روزانه
- فوکوس‌مود: تایمر پومودورو/سشن معاملاتی با صدای محیطی
- دستیار هوش‌مصنوعی «آیرا» برای پرسش دربارهٔ بازار و معرفی بروکر — پاسخ به‌صورت استریم دریافت و رندر می‌شود
- سایدبار مقالات و «مباحث داغ جامعه»

## معماری فعلی

**بدون build، بدون npm، بدون bundler.** محصول خام HTML/CSS/JS است. هر تغییری فقط با زدن دکمهٔ Reload
افزونه در `chrome://extensions` اعمال می‌شود (نه با رفرش صفحه).

آنچه واقعاً در `newtab.html` بارگذاری می‌شود، ۹ اسکریپت مستقل (IIFE) است — بدون ماژول ES:

| فایل | نقش |
|---|---|
| `js/init-state.js` | پیش‌رنگ تم/چیدمان (ضدFOUC) — اولین اسکریپت در body، بدون فراخوانی شبکه |
| `newtab.js` | هستهٔ اصلی: ساعت/تاریخ، جست‌وجو، قیمت‌های لحظه‌ای هر ۴ تب، فید محتوا، سایدبار جامعه، تنظیمات |
| `js/airo.js` | دستیار هوش‌مصنوعی «آیرا» — مودال چت با پاسخ استریم |
| `js/focus.js` | فوکوس‌مود: پومودورو/سشن معاملاتی |
| `js/journal.js` | ژورنال معاملات |
| `js/hub.js` | هاب روزانه: تقویم، آب‌وهوا، دسترسی سریع |
| `js/articles.js` | سایدبار مقالات |
| `js/sidebars.js` | کنترل مشترک باز/بسته‌شدن سایدبارهای جامعه/مقالات |
| `js/tour.js` | تور خوش‌آمدگویی، فقط اجرای اولین بار (قابل اجرای دوباره از تنظیمات) |

### فایل‌های مرده/حذف‌شده (دیگر بارگذاری نمی‌شوند)

نسخه‌های قبلی این پروژه فایل‌های دیگری هم داشتند که یا هرگز واقعاً در `newtab.html` بارگذاری نشدند —
درخت ماژول ES مرده (`js/main.js` + ۲۰ فایل import‌شده از آن: `store`, `settings`, `calendar`, `crypto`,
`watchlist`, `feed`, `community`, `alerts`, `iran-market`, `calculator`, `radar`, `notes`, `timer`,
`utils`, `bg`, `sessions`, `tips`, `tools` و چند فایل دیگر) — یا بعداً اضافه و سپس حذف/revert شدند
(`js/news-timeline.js`، نوار اخبار فارکس، در commit `75ed28a` برگردانده شد). این فایل‌ها دیگر در مخزن
وجود ندارند. اگر جایی (سند، کامنت کد) هنوز به آن‌ها ارجاع می‌دهد، آن منبع عقب‌افتاده است، نه کد.

## ذخیره‌سازی

هر ویجت کلید `localStorage` مستقل خودش را دارد (مثلاً `ib_newtab_v2`, `ib_focus_v3`, `ib_journal_v1`).
**هیچ فراخوانی `chrome.storage.*` در کد نیست** — permission `storage` هم به همین دلیل قبلاً از
`manifest.json` حذف شده (لیست فعلی permissions فقط `notifications` است). هیچ sync بین‌دستگاهی وجود
ندارد. هیچ دادهٔ کاربری به سرور ارسال نمی‌شود، جز پیام‌های چت آیرا که مستقیماً به سرویس هوش‌مصنوعی
می‌رود — جزئیات در [SECURITY.md](SECURITY.md).

## توسعه محلی

```bash
git clone <repo-url>
cd "NewTab Extention"
```

1. در `chrome://extensions` حالت Developer mode را فعال کنید.
2. «Load unpacked» را بزنید و همین پوشه (`NewTab Extention`) را انتخاب کنید.
3. یک تب جدید باز کنید تا داشبورد را ببینید.
4. بعد از هر تغییر کد، در `chrome://extensions` روی دکمهٔ Reload افزونه بزنید.

جزئیات مشارکت و قوانین معماری در [CONTRIBUTING.md](CONTRIBUTING.md).
