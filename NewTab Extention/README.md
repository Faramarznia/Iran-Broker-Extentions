# اکستنشن تب جدید ایران بروکر 🧭

نسخهٔ **ریدیزاین‌شده** صفحهٔ New Tab کروم برای ایران بروکر — با همان زبان طراحی برند (فونت استعداد، آبی `#185adb`، RTL) و لوگوی رسمی در نوبار. هر بار تب جدید باز می‌کنید، این داشبورد نمایش داده می‌شود:

- 🕐 **هیرو با ساعت درخشان**، تاریخ شمسی، خوش‌آمدگوییِ ساعتی و خلاصهٔ جلسهٔ فعال بازار
- 🔍 **باکس جستجو** + جابجایی سریع بین گوگل / ایران بروکر / تریدینگ‌ویو (کلید `Tab`)
- 🧩 **ساجست هوشمند ابزارها**: تایپ کنید، ابزارها و لینک‌های ایران بروکر پیشنهاد می‌شوند (پیمایش با `↑ ↓ Enter`)
- 🛠️ **گرید ابزارها**: لیست بروکرها، مقایسه اسپرد، تقویم اقتصادی، قیمت ارز دیجیتال، صرافی‌ها، پراپ‌فرم‌ها، تحلیل، اخبار، هشدار کلاهبرداری، آموزش
- 💹 **ویجت قیمت لحظه‌ای ارز دیجیتال** با اسپارک‌لاین (داده از CoinGecko، بروزرسانی خودکار هر ۹۰ ثانیه؛ در صورت قطعی، آخرین داده حفظ می‌شود)
- 🌍 **ساعت بازارهای جهانی**: حلقهٔ ۲۴ساعته با چهار سشن فارکس (سیدنی، توکیو، لندن، نیویورک) به‌صورت کمان رنگی و عقربهٔ زنده
- 🛡️ **نکات آگاهی از کلاهبرداری و آموزش** + نمادهای اعتماد (eNamad و ساماندهی) و سلب‌مسئولیت ریسک
- 🎨 تم **تیره/روشن** با جابجایی و ذخیرهٔ خودکار
- ⚙️ تنظیمات قابل ذخیره: نام، موتور پیش‌فرض، **چیدمان (اسکرول / تمام‌صفحه بدون اسکرول)**، رنگ تأکید، گرید پس‌زمینه، نمایش ویجت ارز و فهرست ارزها

## 🚀 نصب روی کروم (برای تست)

۱. این پوشه را روی سیستم خود نگه دارید (از حالت فشرده خارج کنید اگر zip است).
۲. در کروم به آدرس زیر بروید:
```
chrome://extensions
```
۳. گوشه‌ی بالا سمت راست، **Developer mode** را روشن کنید.
۴. روی **Load unpacked** کلیک کنید.
۵. همین پوشه (`iranbroker-newtab`) را انتخاب کنید.
۶. یک تب جدید باز کنید — تمام! ✅

> برای حذف: در همان صفحه `chrome://extensions` روی **Remove** بزنید.

## ✏️ شخصی‌سازی لینک‌ها

اگر مسیر صفحات سایت ایران بروکر متفاوت است، فقط فایل `newtab.js` را باز کنید و آرایه‌های بالای فایل را ویرایش کنید:

- `TOOLS` — کارت‌های ابزار (label، sub، url، رنگ `c`، نام آیکون `icon`)
- `QUICK` — لینک‌های پایین صفحه
- `TIPS` — نکات آگاهی/آموزشی
- `SESSIONS` — سشن‌های فارکس (نام، ساعت باز/بسته به وقت UTC، رنگ)
- `COIN_META` / `SEED` — نام فارسی و دادهٔ پیش‌فرض ارزها برای ویجت قیمت
- `ICONS` — مجموعهٔ آیکون‌های SVG درون‌خط (بدون نیاز به اینترنت/CDN)

تغییرات را ذخیره کنید و در `chrome://extensions` روی دکمه‌ی **Reload (↻)** اکستنشن بزنید.

## 📁 ساختار فایل‌ها

```
NewTab Extention/
├── manifest.json      ← تنظیمات اکستنشن (Manifest V3)
├── newtab.html        ← ساختار صفحه
├── newtab.css         ← استایل، تم تیره/روشن، چیدمان fit، انیمیشن‌ها
├── newtab.js          ← منطق: سرچ، ابزارها، کریپتو، ساعت بازارها، تنظیمات
├── assets/
│   ├── fonts/         ← فونت استعداد (Estedad) — درون‌بسته
│   └── trust/         ← نمادهای اعتماد (eNamad، ساماندهی)
├── icons/             ← آیکون‌های اکستنشن (۱۶/۳۲/۴۸/۱۲۸)
└── README.md
```

> همهٔ آیکون‌های رابط به‌صورت SVG درون‌خط هستند و فونت‌ها درون‌بسته‌اند؛ بنابراین صفحه به‌جز ویجت قیمت ارز (CoinGecko) هیچ وابستگی به اینترنت ندارد.

## ⚠️ نکته درباره داده‌ی ارز دیجیتال

ویجت قیمت از API عمومی **CoinGecko** استفاده می‌کند. اگر به‌خاطر تحریم یا محدودیت شبکه قیمت‌ها لود نشد، پیام خطا نمایش داده می‌شود و بقیه‌ی بخش‌ها بدون مشکل کار می‌کنند. می‌توانید ویجت را از **تنظیمات ⚙️** خاموش کنید.
