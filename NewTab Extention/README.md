# اکستنشن تب جدید ایران بروکر

داشبورد حرفه‌ای معاملاتی برای تب جدید کروم، طراحی‌شده برای معامله‌گران ایرانی بازارهای مالی.

---

## نصب روی کروم (بدون نیاز به Build)

۱. پوشه را روی سیستم خود نگه دارید.
۲. در کروم به آدرس زیر بروید:
```
chrome://extensions
```
۳. گوشه بالا-راست، **Developer mode** را روشن کنید.
۴. روی **Load unpacked** کلیک کنید.
۵. همین پوشه (`NewTab Extention`) را انتخاب کنید.
۶. یک تب جدید باز کنید.

برای اعمال تغییرات کد: در `chrome://extensions` روی آیکون Reload (↻) اکستنشن بزنید.

## ویژگی‌ها

### هستهٔ اصلی (`newtab.js`)

- ساعت درخشان با تاریخ شمسی/میلادی، خوش‌آمدگویی ساعتی و ساعت UTC
- جستجوی یکپارچه (Google / IranBroker / TradingView) با پیشنهادهای زنده از گرید ابزارها و لینک‌های سریع
- گرید ۱۰ ابزار: بروکرها، اسپرد، تقویم، کریپتو، صرافی، پراپ‌فرم، تحلیل، اخبار، هشدار کلاهبرداری، آموزش
- تب‌های قیمت لحظه‌ای: کریپتو (CoinGecko + مدیریت افزودن/حذف ارز)، فارکس/طلا/نفت/DXY (Yahoo Finance)، بازار آزاد ایران و بورس تهران (TGJU + TSETMC)
- فید محتوا (کارت‌های خبری وسط صفحه) از `iranbroker.net` — REST وردپرس با fallback به RSS، فیلتر دسته‌بندی
- سایدبار «مباحث داغ جامعه» — لیست ثابت با چرخش روزانهٔ بذردار، بدون اسکرپ واقعی
- نکات آگاهی از کلاهبرداری/معامله‌گری
- تم تیره/روشن + شیشه مایع اپل، پس‌زمینه شیدر WebGL + اسپارکل Canvas، گالری پس‌زمینه
- مودال تنظیمات: نام، موتور جستجو، رنگ تأکید، چیدمان، تم، ارزهای نمایش‌داده‌شده، دسته‌بندی‌های فید

### ماژول‌های مستقل (`js/`)

هرکدام یک IIFE خودکفا با `localStorage` مجزا هستند — بین آن‌ها state مشترکی وجود ندارد:

| فایل | ویژگی |
|---|---|
| `init-state.js` | اسکریپت پیش‌رنگ (pre-paint) — اولین چیز در `<body>`، همگام و بدون defer/async؛ `data-theme`/`data-layout` را از `localStorage` قبل از اولین رسم صفحه ست می‌کند تا پرش/فلش تم یا چیدمان در ریلود دیده نشود. هیچ فراخوانی شبکه‌ای ندارد. |
| `airo.js` | چت‌بات هوش مصنوعی «آیرا» — مودال چت از نوار جستجو، پیش‌فرض GapGPT با Claude به‌عنوان جایگزین غیرفعال |
| `focus.js` | Focus Mode v3 — تایمر Pomodoro با حلقهٔ SVG، چند حالت و صفحهٔ استراحت |
| `journal.js` | ژورنال معاملاتی — ثبت/ویرایش معاملات، تحلیل روانشناسی، محاسبهٔ خودکار سود/زیان |
| `hub.js` | حالت Hub — کارهای روزانه، تقویم شمسی/میلادی با رویدادهای اقتصادی Forex Factory، آب‌وهوا، گرید دسترسی سریع قابل‌شخصی‌سازی |
| `articles.js` | سایدبار مقالات (لبهٔ چپ) — آینهٔ سایدبار جامعه، از REST وردپرس با fallback به RSS |
| `sidebars.js` | هماهنگ‌کنندهٔ overlay بین سایدبارهای جامعه/مقالات |
| `tour.js` | تور خوش‌آمد تعاملی — فقط بار اول، قابل اجرای دوباره از تنظیمات، آگاه از چیدمان فعلی (simple/data/hub) |

## ساختار فایل‌ها

```
NewTab Extention/
├── manifest.json          ← Manifest V3، مجوزها، CSP
├── newtab.html             ← ساختار HTML (بدون اسکریپت/هندلر inline)
├── newtab.css               ← تمام استایل‌ها، تم‌ها، ریسپانسیو
├── newtab.js                ← هستهٔ اصلی (تنظیمات، جستجو، قیمت‌ها، فید، جامعه، پس‌زمینه)
├── js/
│   ├── init-state.js       ← پیش‌رنگ تم/چیدمان (ضدFOUC)، اولین اسکریپت در body
│   ├── airo.js             ← چت‌بات هوش مصنوعی آیرا
│   ├── focus.js            ← Focus Mode / Pomodoro
│   ├── journal.js          ← ژورنال معاملاتی
│   ├── hub.js               ← حالت Hub (کارها، تقویم، هوا)
│   ├── articles.js          ← سایدبار مقالات
│   ├── sidebars.js          ← scrim سایدبارها
│   └── tour.js               ← تور خوش‌آمد
├── assets/
│   ├── fonts/               ← فونت استعداد (Estedad) — بدون CDN
│   └── trust/                ← نمادهای اعتماد
├── icons/                    ← آیکون ۱۶/۳۲/۴۸/۱۲۸
├── DATA-SOURCES.md            ← فهرست کامل APIهای بیرونی و اینکه هر بخش داده‌اش را از کجا می‌گیرد
└── README.md
```

> هر ۹ فایل بالا (`newtab.js` + ۸ فایل در `js/`) با `<script>` معمولی (بدون `type="module"`) در `newtab.html` بارگذاری می‌شوند — هیچ ماژول ES و هیچ مرحلهٔ build‌ای در کار نیست. `js/init-state.js` زودتر از همه بارگذاری می‌شود (خط ۲۲ در `<body>`)؛ بقیه در انتهای `<body>` (خط‌های ۱۱۴۶ تا ۱۱۵۳).

## نکات فنی

- **بدون npm / بدون build** — HTML/CSS/JS خالص
- **بدون CDN** — همه فونت‌ها و آیکون‌ها درون‌بسته
- **CSP compliant** — `script-src 'self'`؛ هیچ inline script یا inline event handler در HTML یا در HTML تولیدشده توسط JS نیست
- **بدون ماژول‌های ES و بدون state مشترک** — یک هستهٔ اصلی (`newtab.js`) + ۸ فایل مستقل IIFE در `js/`، هرکدام `localStorage` خودشان را دارند
- **ذخیره‌سازی** — فقط `localStorage` استاندارد؛ هیچ فراخوانی `chrome.storage.*` در کد نیست (permission `storage` هم به همین دلیل از `manifest.json` حذف شده)
- **RTL کامل** — همه متن‌ها فارسی، جهت راست‌به‌چپ
- **Timeout** — بیشتر درخواست‌های شبکه با `AbortController` timeout دارند
