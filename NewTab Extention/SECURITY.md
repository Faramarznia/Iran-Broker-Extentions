# سیاست امنیتی

> این سند بر پایهٔ بررسی مستقیم کد امروز (نه وضعیت حسابرسی قبلی) نوشته شده. تاریخ آخرین تأیید:
> ۲۰۲۶-۰۸-۱۸.

## گزارش آسیب‌پذیری

اگر آسیب‌پذیری امنیتی پیدا کردید، لطفاً **Issue عمومی باز نکنید**. مستقیماً با تیم محصول ایران بروکر
تماس بگیرید (کانال داخلی/ایمیل امنیتی تیم). جزئیات فنی آسیب‌پذیری را تا رفع کامل آن منتشر نکنید.

## مسائل شناخته‌شده (در حال رفع)

- **افشای کلید API در کلاینت (P0 — REQ-1، هنوز باز):** سرویس چت «آیرا» (`js/airo.js`) در حال حاضر
  کلید API را به‌صورت hardcoded در کدی نگه می‌دارد که در مرورگر کاربر اجرا می‌شود. هر کاربری با ابزار
  توسعه‌دهندهٔ مرورگر می‌تواند این کلید را استخراج کند. رفع این مورد نیازمند عبور تماس‌های آیرا از یک
  بک‌اند واسط (proxy) است تا کلید هرگز به کلاینت ارسال نشود. تا رفع کامل، این کلید را دارای ریسک
  سوءاستفادهٔ مالی در نظر بگیرید و دسترسی/سقف مصرف آن را محدود نگه دارید.

## مجوزها و سطح دسترسی

- **مجوزهای Chrome:** فقط `notifications` (اعلان پایان سشن فوکوس‌مود از طریق Web Notification API
  استاندارد، نه `chrome.notifications`). مجوز `storage` قبلاً در یک حسابرسی جداگانه از
  `manifest.json` حذف شد چون هیچ فراخوانی `chrome.storage.*` در کد نبود — تمام ذخیره‌سازی محلی از
  `localStorage` استاندارد استفاده می‌کند. هیچ مجوز دیگری (تب‌ها، تاریخچه، کوکی و غیره) درخواست
  نمی‌شود.
- **اتصال شبکه:** فقط به دامنه‌های فهرست‌شده در `manifest.json` (`connect-src`/`host_permissions`)،
  فهرست کامل در [DATA-SOURCES.md](DATA-SOURCES.md). هر درخواست به آدرس دیگر توسط CSP مسدود می‌شود.
- **دادهٔ کاربر:** تمام state (تنظیمات، ژورنال، سشن‌های فوکوس) فقط در مرورگر محلی کاربر ذخیره
  می‌شود، بدون sync بین‌دستگاهی. تنها استثنا پیام‌های چت آیرا است که مستقیماً به سرویس هوش‌مصنوعی
  فعال (`api.gapgpt.app`) ارسال می‌شود — کاربر می‌تواند «حالت خصوصی» را در هدر چت فعال کند تا هیچ
  مکالمه‌ای در `localStorage` ذخیره نشود (ارسال به سرویس هوش‌مصنوعی باز هم اتفاق می‌افتد، چون برای
  گرفتن پاسخ ضروری است — فقط ذخیرهٔ محلی غیرفعال می‌شود).

## نسخه‌های پشتیبانی‌شده

فقط آخرین نسخهٔ منتشرشده در Chrome Web Store پچ امنیتی دریافت می‌کند. نسخه‌های قدیمی‌تر پشتیبانی
نمی‌شوند — کاربران باید به آخرین نسخه بروزرسانی کنند.
