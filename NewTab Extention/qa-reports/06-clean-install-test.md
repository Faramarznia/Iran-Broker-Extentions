# تست ۶: نصب تمیز

**وضعیت: ✅ PASS**

## نحوهٔ اجرا

```bash
node qa-reports/tools/06-clean-install.js
```

پروفایل کاملاً تازهٔ Puppeteer (بدون هیچ `localStorage` قبلی) `newtab.html` را برای اولین بار باز می‌کند، سلامت DOM و کنسول را می‌خواند، تور را رد می‌کند (همان‌طور که یک کاربر واقعی می‌کند)، و دوباره reload می‌کند تا مطمئن شود تور برای بار دوم نمایش داده نمی‌شود.

## نتیجهٔ واقعی

### ۱. خطای Console؟
```
console errors: 2
 - CORS: forum.iranbroker.net/hot.json (از origin تهی 'file://' مسدود شد)
 - net::ERR_FAILED (همان درخواست)

page (uncaught) errors: 0
```
⚠️ این ۲ خطا **مصنوع محیط تست است، نه باگ محصول**: `forum.iranbroker.net` هدر CORS مجاز نمی‌فرستد، پس فقط وقتی از طریق `host_permissions` واقعی یک اکستنشن نصب‌شده فراخوانی شود کار می‌کند (که CORS را دور می‌زند) — نه وقتی صفحه مستقیم با `file://` باز شود (محدودیت زیرساخت این‌جا، توضیح کامل در `qa-reports/README.md`). **صفر خطای غیرمنتظره** (uncaught exception) وجود داشت — این معیار اصلی PASS این تست است.

### ۲. آیا ویجت‌ها مقدار seed/پیش‌فرض درست دارند؟
```json
{
  "toolsGridCount": 10,
  "cryptoListState": "BBTCبیت‌کوین$62,992+0.40٪EETHاتریوم$1,878+0.30٪...",
  "heroGreeting": "صبحت بخیر رفیق",
  "heroDate": "۲۴ مرداد",
  "clock": "07:48",
  "anyNaNOrUndefinedInBody": false
}
```
✅ گرید ابزار با ۱۰ آیتم پیش‌فرض کامل است. ویجت کریپتو دادهٔ زنده واقعی نشان داد (چون CoinGecko برخلاف forum.iranbroker.net، از این محیط CORS را اجازه داد). خوش‌آمدگویی/تاریخ/ساعت پر هستند. هیچ رشتهٔ `NaN` یا `undefined` در کل بدنهٔ صفحه دیده نشد.

### ۳. تور خوش‌آمدگویی
```
Pass 1 (اولین لود): tour visible = true         ✅ درست
ib_tour_v1_done بعد از «رد کردن»: "1"           ✅ درست ذخیره شد
Pass 2 (reload با همان localStorage): tour visible = false   ✅ دیگر نمایش داده نشد
```

⚠️ **یادداشت روش‌شناسی (خودِ تست، نه محصول)**: اولین تلاش این بخش از یک سلکتور خیلی کلی (`[class*="ibt-"]`) استفاده می‌کرد که چون `js/tour.js` یک دکمهٔ «نمایش دوبارهٔ راهنما» با کلاس `ibt-replay-sec` را **همیشه** (حتی وقتی تور دیده شده) به پنل تنظیمات اضافه می‌کند (`injectReplayButton()`، خط ۳۸۹-۴۰۱، قبل از چک `done`)، آن سلکتور در هر دو Pass به‌اشتباه «true» می‌داد. با سلکتور دقیق (`.ibt-backdrop, .ibt-pop` — که فقط وقتی `start()` واقعاً اجرا شود در DOM هست) دوباره تست شد و نتیجهٔ واقعی همان چیزی بود که بالا آمد. این را می‌آورم تا مشخص شود نتیجه با دقت verify شده، نه فرض اول.
