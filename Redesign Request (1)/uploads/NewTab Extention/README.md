# اکستنشن تب جدید ایران بروکر 🧭

یک صفحه‌ی New Tab کامل و خلاقانه برای کروم که هر بار تب جدید باز می‌کنید، داشبورد ایران بروکر را نمایش می‌دهد:

- 🔍 **باکس جستجوی گوگل** + جابجایی سریع بین گوگل / ایران بروکر / تریدینگ‌ویو (با کلید `Tab`)
- 🧩 **ساجست هوشمند ابزارها**: تایپ کنید، ابزارهای ایران بروکر پیشنهاد می‌شوند
- 🛠️ **گرید ابزارها**: لیست بروکرها، مقایسه اسپرد، تقویم اقتصادی، قیمت ارز دیجیتال، صرافی‌ها، پراپ‌فرم‌ها، تحلیل، اخبار، هشدار کلاهبرداری، آموزش
- 💹 **ویجت قیمت لحظه‌ای ارز دیجیتال** (داده از CoinGecko، بروزرسانی خودکار هر ۹۰ ثانیه)
- 🌍 **وضعیت سشن‌های فارکس** (سیدنی، توکیو، لندن، نیویورک) به‌صورت زنده
- 🛡️ **نکات آگاهی از کلاهبرداری و آموزش** با لحن برند Sage ایران بروکر
- 🕐 ساعت و **تاریخ شمسی**، خوش‌آمدگویی بر اساس ساعت روز
- 🎨 تم تیره/روشن + انیمیشن پس‌زمینه‌ی نمودار مالی
- ⚙️ تنظیمات قابل ذخیره (نام، موتور پیش‌فرض، ارزها، نمایش ویجت‌ها)

---

## 🚀 نصب روی کروم (برای تست)

۱. این پوشه را روی سیستم خود نگه دارید (از حالت فشرده خارج کنید اگر zip است).
۲. در کروم به آدرس زیر بروید:
```
chrome://extensions
```
۳. گوشه‌ی بالا سمت راست، **Developer mode** را روشن کنید.
۴. روی **Load unpacked** کلیک کنید.
۵. همین پوشه (`iranbroker-newtab`) را انتخاب کنید.
۶. یک تب جدید باز کنید — تمام! ✅

> برای حذف: در همان صفحه `chrome://extensions` روی **Remove** بزنید.

---

## ✏️ شخصی‌سازی لینک‌ها

اگر مسیر صفحات سایت ایران بروکر متفاوت است، فقط فایل `newtab.js` را باز کنید و آرایه‌های زیر را ویرایش کنید:

- `IB_BASE` — دامنه اصلی (پیش‌فرض `https://iranbroker.net`)
- `TOOLS` — کارت‌های ابزار (label، sub، url، رنگ، آیکون)
- `QUICK_LINKS` — لینک‌های پایین صفحه
- `TIPS` — نکات آگاهی/آموزشی
- `COIN_META` — نام فارسی ارزها برای ویجت قیمت

تغییرات را ذخیره کنید و در `chrome://extensions` روی دکمه‌ی **Reload (↻)** اکستنشن بزنید.
